# Agentic Query

ORM-native AI query runtime for Rails and Node.js applications.

Agentic Query is designed around a strict separation between LLM reasoning, query representation, policy enforcement, and database execution.

## Status

Early development. The initial milestone focuses on a deterministic query contract and policy layer before autonomous LLM execution.

See [`docs/ROADMAP.md`](docs/ROADMAP.md) for the planned milestones.
